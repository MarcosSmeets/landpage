// Featured Project

Titan

High-fidelity physics simulation engine for aerospace applications. C++ core, .NET integration, React mission control.

[PHYSICS]

N-body gravitational simulation with configurable integrators and high-precision orbital mechanics solvers.

[INTEGRATION]

.NET wrapper exposing the C++ engine through a clean, idiomatic C# API for rapid application development.

[ATTITUDE]

Quaternion-based attitude determination and control system with reaction wheel and thruster models.

[TELEMETRY]

Real-time data streaming pipeline for simulation state visualization and post-run analysis.

[INTERFACE]

React-based mission control dashboard with live telemetry charts, 3D orbit visualization, and scenario management.

[PRESETS]

Pre-configured simulation scenarios including LEO, GEO, lunar transfer, and interplanetary trajectory templates.

C++ CMake C# / .NET React TypeScript WebSocket Docker
